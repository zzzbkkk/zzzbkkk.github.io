## 本地预览

需要 Node.js 20 或以上，不需要安装 npm 依赖。

```powershell
Set-Location 'E:\个人项目\个人网站'
npm run dev
```

打开 <http://127.0.0.1:4323/zh/>，英文版为 <http://127.0.0.1:4323/en/>。

该地址依赖本机预览进程。请保持运行命令的终端开启；服务停止或电脑重启后，需要再次执行上述命令。若浏览器提示“拒绝连接”，先确认服务正在运行。`127.0.0.1` 只能用于本机预览，供招聘方访问需要另行部署到公网。

所有内容页统一使用蜻蜓，背景工具仅保留暂停和恢复。旧链接的 `scene` 参数会被清理，其他查询参数与 hash 保留；旧折带会话状态和快照不再进入页面。跨页、中英文切换与回访时继续保留用户的暂停偏好。

- `npm run build`：重新生成 `dist/`，该目录只放构建产物。
- `npm start`：启动已构建的本地预览。
- `npm run check`：检查构建页面、双语路由、内链、资源、模块和内容分类。
- 页面源码或静态资源修改后运行 `npm run build` 并刷新页面；本地服务无需重启，没有自动热更新。修改 `server.mjs` 后需要重启服务。
- 如端口被占用，可先设置 `$env:PORT='4324'` 再运行 `npm start`。

公网部署目标为 <https://zzzbkkk.github.io/>，源码仓库为 <https://github.com/zzzbkkk/zzzbkkk.github.io>。发布产物是 `dist/`，保留目录式 HTML 路由；GitHub Pages 根路径直接显示中文首页，本地预览服务将 `/` 重定向到 `/zh/`。

GitHub Pages 自动部署配置见 `.github/workflows/deploy-pages.yml`，发布流程见 [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)。Pages 使用静态根首页和根 404，不运行本地服务；仓库启用 GitHub Actions 后，推送到 `main` 会自动构建、检查并发布。线上验证结果以 `docs/QA.md` 为准。

本地服务保留 CSP，仅监听 `127.0.0.1`。资源响应使用 `Cache-Control: no-cache` 和弱 ETag：浏览器重新验证后，未变化的文件返回 304，避免重复传输简历与模型；构建更新后可获取新版本。WASM、GLB 分别使用 `application/wasm`、`model/gltf-binary`。路径解析和真实文件路径均限制在构建目录内。

## 页面与内容

两种语言均有首页、作品集、博客、关于我，以及四个独立作品详情页，共 16 个内容页面。

- 首页及作品集顺序为 OpenClaw → OiiOii → Drimo → Yesoul T5，详情页“继续阅读”沿用该顺序。首页显示随滚动更新的 `01 / 04` 位置提示，分母由真实作品数量生成。
- OpenClaw：`kind: 'experience'` 的项目经历概览，只依据现有简历展示业务范围、本人参与和材料依据，来源为本地简历。尚未提供的具体问题、关键决策、验证和结果不编造，后续更新资料再补充。
- OiiOii、Drimo：产品分析，正文限于此前已记录的研究片段，不作为完整测评或本人开发成果。原文入口紧随标题和摘要，正文提供章节导航及文末原文入口。
- Yesoul T5：明确标为“项目资料 · PRD”，保留摘要、资料范围及标题区域的 PRD 原文入口，不扩写成完整项目案例。
- 首页介绍先呈现 AI 内容生成与运营工具的需求设计、Prompt 策略和效果评测经验，再说明视觉传达设计背景。手机使用 `bioShort` 的同事实短版本，收紧联系区并将作品、简历按钮并排，让作品更早进入视野。
- 博客：`posts` 仍为空，保留导航；明确说明独立文章正在整理，提供 OiiOii、Drimo 两项现有产品研究的真实阅读入口，不生成假博客或日期。
- 关于我：依次展示个人简介、相关经历、关注方向、教育、简历与联系；经历中突出时间、岗位和参与内容，并连接 OpenClaw 概览。
- 简历：保留用户原始中文 PDF，标记“现有版本”，不冒充最新或英文简历。
- GitHub、人人都是产品经理：尚未提供个人 URL，桌面导航和折叠菜单均隐藏入口；提供地址后启用，不显示不可点占位。
- 所有作品封面为基于已核实资料制作的 HTML 内容示意图，带中英文标注，不代表真实产品截图。OpenClaw 使用数据查询、规则推送、周报生成三个并列范围，不绘制产品流程或系统架构；OiiOii 使用横向四阶段流程；Drimo 区分来源组与制作组，封面容器宽度 ≤440px 时上下排列；T5 使用左右对称端点和无方向连接线，仅表达 App 与跑步机的功能适配关系。不添加未经核实的产品图片或功能。
- 首页卡片使用一句 `cardSummary` 与紧凑留白，封面不强制比例，内部最小高桌面 188px、手机 184px，Drimo 手机至少 220px。作品集卡片宽屏优先 16:6、详情宽屏优先 16:5，最小高 204px；手机通常优先 16:8、最小高 220px，Drimo 在手机随分组与文字自然增高。宽度始终受容器约束，最小高度和完整内容优先于比例；未来真实截图可采用 16:9。
- 首页和关于页邮箱保留 `mailto:` 并提供复制按钮；复制失败时选中邮箱供手动复制，无 JavaScript 时仍可点击发信。

正常内容页包含对应中英文页面的相对 `hreflang`、分页面描述、Open Graph 语言和基础 Twitter 卡片元数据。404 页使用 `noindex`、不输出 `hreflang`，切换语言进入另一语言首页且不高亮主导航。当前没有确定公网域名，不设置虚构 canonical 或站点地图地址。

## 动效和阅读

片头在每个标签页会话首次直接进入首页时播放，总长三秒：0–450ms 显示部分翅缘，450–1350ms 渐显主体与全翼，1350–1740ms 用 390ms 淡入姓名，1740–2370ms 稳定显示。姓名保持原字号：桌面 `clamp(72px, 9vw, 160px)`、手机 `clamp(36px, 10vw, 56px)`。2370–2550ms 用 180ms 退出；2550ms 起，导航、介绍、首张作品相隔 90ms 出现，每批持续 270ms，最后一批在 3000ms 完成，同时解除首页 `inert`、释放滚动与交互。桌面退场与首页出现伴随 8px 轻微位移，手机或粗指针设备仅淡入。可点“跳过”或按 Escape；减少动态效果、深链接和无 JavaScript 均直接显示内容。同会话刷新和导航不重播。要再次查看片头，可以新开独立标签页会话，或在开发工具中删除会话存储 `bk-entry` 后刷新。

首页、作品集、博客、关于我和作品详情统一使用 ASCII 蜻蜓，保留原版四翼扇动与橙色字符拖尾。片头专用取景为 `x: 0 / zoom: 1`，完整三秒内保持居中；`intro:end` 后同一 Canvas 平滑调整至首页构图，内容立即可用。页面用真实 `elapsed / 1500`、限制在 0–1 的进度调用 `setIntroProgress()`，迟加载模型直接进入当前阶段；超时或跳过后直接使用完整材质和普通首页构图，不补播、不新增等待。普通页面默认进度为 1。未挂载实时模型时，静态备用图只做 1350ms 淡入，不具备精确的翅缘材质阶段；实时就绪后隐藏备用图。资源失败仍按既有降级规则显示内容。本版没有扫光或作品背景响应，原模型、shader 与相关资源完整保留。

字符图集修为 16 档 ` *._<>,::./O#SF+`，只有零亮度档为空白。旧第 7、8 档空格曾使中灰胸部与翅根断开，本版补回原有字符风格中的标点，恢复主体的连续轮廓；不靠整体提亮或新增颜色修补。

首页取景略向左移并拓宽（`x: -0.20 / zoom: 1.12`），作品集、阅读页、博客分别保持 `0.10 / 1.04`、`0.22 / 1.08`、`0.12 / 1.16`。`zoom` 越大视野越宽；Canvas 宽度 ≤800px 时，横向偏移缩至桌面的 27%，视野变化缩至 65%，基础视角使用 `17°`。主体采用中性灰阶和微弱翅缘光，枝干进一步压暗；亮度按 22 秒余弦周期缓慢变化。精细鼠标的轻微视差在停留 0.65 秒后逐渐回中，触摸不驱动模型偏转。具体材质与运动参数见 `DESIGN.md` 第 5 节。

每页只运行一套蜻蜓场景；失焦或后台暂停，离开当前页面释放，下一内容页重新挂载。减少动态效果、节省流量或 WebGL 不可用时显示蜻蜓静态备用图。404 不加载背景。

同源内容导航会保存最长 15 秒、只供匹配目标路径使用的蜻蜓背景帧及姿态。下一页先用可用快照，再接入自身新建的场景并平滑调整构图；不接受旧折带快照和状态，也不跨页面共用一个运行实例。支持原生跨文档 View Transition 的浏览器中，导航底板过渡 200ms、正文淡入 180ms；不支持时执行普通导航及目标页淡入。背景不影响路由、深链接或后退，不要求浏览器必须具备视图过渡能力。

OiiOii、Drimo、T5 三张图示统一为 36px 圆节点和 1px 线条，静止时使用灰阶。OpenClaw 为三个并列范围，悬停或键盘进入后上沿依次轻亮约 700ms，不表示流程顺序；OiiOii 四阶段依次轻亮约 840ms，Drimo 素材到分镜与制作的路径轻亮约 980ms，T5 两端与无方向适配线同时轻亮 560ms。仅用现有橙色，不循环；同一卡片内切换链接不重复，离开后可重播。触屏直接显示全部内容。

作品卡片首次进入可视区域时使用 220ms 淡入，桌面另有 12px 上移；手机或粗指针设备仅淡入。`bk-seen-work` 按作品记录本标签页会话内已看状态，首页、作品集、语言切换和返回不会重播已看作品；未看作品在浏览器返回缓存页后继续被观察。

移动菜单在导航下方用 180ms 展开、120ms 收起，栏目相隔 20ms 淡入；保留焦点管理和 Escape 关闭。主次按钮、筛选和菜单按钮按下缩至 98%，过渡 100ms。复制邮箱按钮固定 7em 宽，状态文字淡入 160ms，约 2400ms 恢复。分析页章节导航保留原生 hash 与历史记录，平滑定位后将焦点交给标题，并显示 700ms 的橙色到达标记。减少动态效果时去除这些动画和平滑滚动，保留立即可用的状态反馈。

博客、关于我正文背后使用中心不透明度桌面 0.42、手机 0.52 的渐隐黑色阅读层；作品集仅标题区域加 0.42 遮罩。详情长文继续使用桌面 0.76、手机 0.72 的保护。背景交互持续运行，全局背景透明度维持桌面 0.46、手机 0.35。≥1200px 导航高 56px；辅助姓名缩小，卡片标题加强，卡片为 12px 圆角与完整的 1px 透明边框占位，悬停显示装饰线。选中导航使用 `#1D1D1D` 底板，铺满链接并继承圆角。

首页个人介绍背后沿用局部渐隐黑色保护层，中心不透明度为桌面 0.42、手机 0.54；中间留白与作品栏继续展示背景。沿用 v2.8 的平缓光照、较暗枝干、原扇翼与鼠标拖尾。封面顶部使用轻微中性灰高光，正文继续使用稳定实色底；没有新增主色或产品功能描述。

每个内容页仅保留“暂停背景 / 恢复动效”：首页双栏模式下位于左下角，其他页面位于标题或返回入口旁。暂停选择保存在标签页会话中，刷新、页面和语言切换及浏览器返回后仍保留，新会话默认运行动效。已加载时暂停保留当前画面；带暂停偏好重新进入时显示有效的蜻蜓同源快照或静态备用图，恢复后按需加载。失焦后恢复不会覆盖用户主动暂停的选择，减少动态效果或节省流量时隐藏播放控件。

宽度至少 1200px、高度至少 760px 且介绍能放下时，作品列表独立原生滚动；其他情况使用自然页面滚动。详情返回首页恢复列表位置，语言切换保留作品位置及作品集筛选。
