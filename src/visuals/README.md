# ASCII 蜻蜓背景

v3.0.2 · 三秒入场（2026-10-04）。本版仅将居中片头总长改为三秒，各阶段按 1.5 倍整体放慢，依次呈现部分翅缘、主体与全翼、姓名和首页；不增加扫光或作品背景响应。v3.0 的导航、卡片、字号、内容、全站唯一蜻蜓背景、中灰字符档和主页面阅读遮罩保持原规则。字符折带不再出现在页面。`src/client/scene-bootstrap.js` 固定首帧形态并清理旧 `scene` 参数与折带会话状态，保留其他查询参数、hash 和暂停偏好。`src/client/background.mjs` 负责暂停、生命周期、真实片头进度、构图交接与同源导航衔接，页面不再提供形态切换。验证结果以 `docs/QA.md` 为准。

## 当前渲染器

蜻蜓运行入口为 `interactive-dragonfly.js`，使用真实 GLB 模型、Three.js 和原版 ASCII / 鼠标拖尾 GLSL。

```js
const visual = await mountInteractiveDragonfly(canvas);
visual.pause();
visual.resume();
visual.dispose();
```

- `getState()` 提供本地验证所需的帧数、四翼角度、鼠标与拖尾状态、GPU 资源统计，以及视差和光照诊断；当前 `source` 为 `original-model-refined-lighting`。
- `dragonfly-shaders.js` 提取自用户选定参考工程的公开着色器，包含模型、ASCII、40 点拖尾三套程序。
- `public/vendor/three.js` 为参考工程中独立 Three.js 构建，`dragonfly-loaders.js` 为仅保留 Three 依赖的 GLTF / Draco loader；无需 Nuxt、Vue、GSAP 或原站服务。
- `public/vendor/draco/` 和 `public/models/dragonfly.glb` 均本地托管，解码完成关闭 workers。加载失败释放已创建资源并抛错，页面保留静态图。
- 保留原版首屏姿态、真实四翼运动与字符边缘橙色拖尾，精修构图和有限鼠标视差。原站由长页滚动驱动的飞离和后续模型切换不应用于本站作品列表。
- 最高 30fps、DPR 上限 1.5；失焦、后台或上下文丢失时暂停。`dispose()` 释放事件、RAF、观察器、材质、纹理、几何和 WebGL 上下文。
- 首页与三秒片头共用一个 Canvas。片头计时和备用图由页面控制；减少动态效果或节省流量时不挂载 WebGL。
- `public/art/dragonfly-ascii.svg` / PNG 仍作静态备用。旧 `dragonfly.js` / `dragonfly-data.js` 是前版 Canvas 2D 原型，当前构建不包含它们；`generate-dragonfly.mjs` 保留为静态图离线生成工具。

## 居中片头与主体连续性

- 片头专用 `intro` 构图为 `x: 0 / zoom: 1`，完整三秒内保持居中。`intro:end` 后通过 `setComposition()` 平滑调整至首页 `-0.20 / 1.12`，复用场景和扇翼相位，不延迟内容交互。跳过同样以实际退出事件交接。
- `setIntroProgress(progress)` 控制本地派生材质的入场阶段，页面按真实经过时间计算 `clamp(elapsed / 1500, 0, 1)`，主体渐显的归一化区间仍为 0.3–0.9。普通页默认进度为 1，使用完整材质；不修改原始 `dragonfly-shaders.js`，不增加渲染 pass。
- 实时模型在 0–450ms 显示部分翅缘，450–1350ms 渐显主体与全翼；姓名在 1350–1740ms 用 390ms 淡入，1740–2370ms 稳定显示。桌面字号保持 `clamp(72px, 9vw, 160px)`，手机保持 `clamp(36px, 10vw, 56px)`。
- 2370–2550ms 姓名用 180ms 退场；2550–3000ms 首页导航、介绍、首张作品按 90ms 间隔分批出现，每批 270ms。整个片头在 3000ms 完成并解除首页 `inert`，不新增等待。
- 加载期间再次检查构图与真实进度，迟到模型直接显示当前阶段，不从零补播。片头已结束或跳过时，在暴露首个实时画面前采用完整材质和普通首页构图，不补播居中移动或材质入场。
- 未挂载实时模型时，静态备用图仅做 1350ms 淡入，不具备精确的部分翅缘与主体材质阶段；实时场景就绪后隐藏备用图，避免叠加。模型失败、WebGL 不可用、减少动态效果、节省流量、跳过及 Escape 沿用既有降级或退出规则，正文不被资源加载阻塞。
- 字符图集为 16 档 ` *._<>,::./O#SF+`，仅第 0 档为空白。修复原第 7、8 档空格挖空中灰胸部与翅根的问题；既有字符风格与 ASCII shader 保留，不提高全屏亮度或增加渲染层。
- CSS 全局透明度仍为桌面 0.46、手机 0.35。首页介绍遮罩中心减至 0.42 / 0.54，博客和关于我减至 0.42 / 0.52，作品集标题为 0.42；详情正文维持 0.76 / 0.72。参数顺序为桌面 / 手机，遮罩仍渐隐且不拦截交互。

## 沿用 v2.8 视觉调校

- 首页 `x: -0.20 / zoom: 1.12`，略向左移、拓宽视野；作品集 `0.10 / 1.04`、阅读页 `0.22 / 1.08`、博客 `0.12 / 1.16` 保持原取景。`zoom` 为视野倍率，越大取景越宽。
- Canvas 宽度 ≤800px 时，横向偏移缩至 27%、视野变化缩至 65%，基础视角 `17°`；桌面基础视角仍为 `11°`。
- 主体中性灰阶映射 `0.92`、法线强度 `0.56`；本地派生材质使用 `1.1` 对比度与 `0.075` 翅缘光，枝干映射 `0.22`、边缘光为 `0`。不改动原始 `dragonfly-shaders.js`，不增加渲染 pass 或 bloom。
- 光照采用 22 秒余弦周期，主体亮度 `0.23–0.39`、枝干 `0.30–0.78`，同周期伴随小幅光向变化。四翼频率与橙色拖尾逻辑不变。
- 仅精细鼠标产生有限视差：Y 轴最多 `0.004rad`、X 轴最多 `0.0024rad`；停留 `0.65s` 后以速率 `2.4` 指数衰减回中，跟随速率 `2.8`。触摸不驱动模型偏转，原生滚动不受影响。
- v2.8 调校前渲染器保存在 `archive/dragonfly-v2.7/interactive-dragonfly.js`，原模型和着色器资源继续保留。
